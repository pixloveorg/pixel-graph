# pixel-graph

A drawing, not a work log. The commits in this repository are empty and back-dated on
purpose: each one is a pixel in [pixloveorg](https://github.com/pixloveorg)'s contribution
graph. Pick a year next to the graph to see its picture: 1990–2021 the year with an icon
of its time, then the story of [Pixlove](https://pixlove.org/), a pixel-art editor and
community.

`node draw.mjs preview` prints every year in the terminal; `node draw.mjs build` rebuilds
the history from the drawings.
